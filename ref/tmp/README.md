# kNN-VC reference clips

Put the kNN-VC target-speaker clips here (they are not in the repository).

A speaker set is all `.wav` files starting with the same prefix, e.g. `in_aca_*.wav`,
about 10 minutes of 16 kHz mono speech per speaker. Without them, the two
"Preserve natural speech rhythm" options are rejected with a clear error.
See README step 6.
