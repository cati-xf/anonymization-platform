Listening examples

GitHub repository

Three utterances from the BD-PÚBLICO read-speech test set, each from a different speaker, taken from the thesis evaluation. Every entity is generalized: removed words are struck through and replacements are highlighted. Each clip shows what the Whisper model hears in it, and the word error rate (WER) against the intended anonymized text. Voice-conversion-only clips keep the original words, so they have no WER.

The three examples:

  1. Person name
  2. Locations (city and country)
  3. Organizations and a city
