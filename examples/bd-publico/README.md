# Examples: BD-PÚBLICO

**[▶ Listen to all examples on one page](https://cati-xf.github.io/anonymization-platform/examples/)**

Outputs of the platform on three utterances from the BD-PÚBLICO European Portuguese
read-speech test set (three different speakers). They come from the thesis evaluation run,
with every entity label set to `gen` (generalize).

Each folder has the same 11 clips: the original, the three content-anonymization backends,
kNN-VC voice conversion, and the same pipeline on a noisy copy (MUSAN noise added at the
SNR given per example) with background noise left in, removed, or separated and re-mixed.
All noisy clips are anonymized with F5-TTS in-place editing (the default backend).
Clips are 128 kbps MP3.

**ASR of output** is what the fine-tuned Whisper (CAMÕES) model transcribes from each clip.
**WER** is computed against the intended anonymized text. Voice-conversion-only clips keep
the original content, so they have no anonymized reference and no WER.
